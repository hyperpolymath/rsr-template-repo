== Census

0 rows `proven`, 0 `tested-only`, 0 `argued`, 7 `open`: 7 rows in all.

Write the census as a count of rows by status, with the denominator. Never
write a percentage: a count of rows is not a measure of confidence
(README-EXPLAINME §5, PROOF-POLICY §8.4).

== Ledger

One row per obligation, including the ones that are only argued or still
open. Status is one of `proven`, `proven-with-postulates`, `argued`,
`tested-only` or `open`. A `proven` row names the checker, its version and
flags. A row is never stronger than the weakest step it depends on.

The seven rows below are the template's mandatory obligations from
`PROOF-NEEDS.adoc`. The files under `verification/proofs/` prove example
statements about the template's example ABI, not this repository's. Restate
each obligation for this repository's own seam, and move a row out of
`open` only on a receipt below.
