== Dangerous Patterns (BANNED)

The following MUST NOT appear anywhere in proof files:

[cols="2,2,3", options="header"]
|===
| Pattern | Language | Meaning

| `believe_me` | Idris2 | Unsafe cast / trust-me
| `assert_total` | Idris2 | Skip totality check
| `postulate` | Idris2/Agda | Unproven axiom
| `sorry` | Lean4 | Incomplete proof
| `Admitted` | Coq | Incomplete proof
| `unsafeCoerce` | Haskell | Unsafe type cast
| `Obj.magic` | OCaml/ | Unsafe type cast
| `unsafe` (unaudited) | Rust | Unsafe block without safety comment
|===

CI will reject any PR introducing these patterns (enforced by `panic-attack assail`).

== Prover Selection Guide

The normative mapping is `3-practice/PROOF-POLICY.adoc` §1 in
`metadatastician/standards`; `verification/proofs/README.adoc` maps it onto this
tree. In short:

[cols="2,2,3", options="header"]
|===
| Obligation | Prover | Notes

| APIs, ABIs and engineering properties | *Idris2* | Statements about one repository's types, functions or wire formats
| Theory | *Agda*, rechecked in *Rocq* and *Lean* | `agda/` is the source of truth; no Mathlib
| Rust code | *Creusot* with *Pearlite* contracts, and *Verus* | On the code itself (policy §1.2: plan scopes for both verifiers; Kani for `unsafe`/FFI seams)
| Ada code | *SPARK* | On the code itself, via `gnatprove`
| Distributed protocols | *TLA+* | Policy §4 exception; report results as TESTED with their bounds
|===
