== Template Example Obligations (REPLACE OR DELETE ON MINT)

TEMPLATE — these rows describe the example files the template ships under
`src/interface/` and `verification/proofs/`. They are *not* obligations of a
minted repo, and a repo must not record them as its own unless it keeps those
files. On mint, do one of:

* keep a group *only if* the repo has that surface (any ABI or FFI for the ABI
rows, whatever implements it; a typed public API for the typing rows), and then
repoint each row at the repo's own file and judge its status for real. Where an
example row does not fit the repo's interface (say, a C ABI with no Idris2
layer), replace it with the obligation that interface does carry; never drop
the group while the surface exists; or
* delete the group and record here why it does not apply
(a pure-theory repo has no ABI, FFI or exported API to state them about).

A row whose file does not exist in this repo is a defect, not an obligation.
(Name no repository here: the mint's self-name pass rewrites the template's
name into the child's, which once made this line credit the child.)

== Dangerous Patterns (BANNED)

The following MUST NOT appear anywhere in proof files:

[cols="2,2,3", options="header"]
|===
| Pattern | Language | Meaning

| `believe_me` | Idris2 | Unsafe cast / trust-me
| `assert_total` | Idris2 | Skip totality check
| `postulate` | Idris2/Agda | Unproven axiom
| `sorry` | Lean4 | Incomplete proof
| `Admitted` | Coq | Incomplete proof
| `unsafeCoerce` | Haskell | Unsafe type cast
| `Obj.magic` | OCaml/ | Unsafe type cast
| `unsafe` (unaudited) | Rust | Unsafe block without safety comment
|===

CI will reject any PR introducing these patterns (enforced by `panic-attack assail`).

== Prover Selection Guide

The mapping is set by `3-practice/PROOF-POLICY.adoc` §1 in
`metadatastician/standards`, not by this table: where they differ, the policy
wins. `verification/proofs/README.adoc` maps it onto this tree.

[cols="2,2,3", options="header"]
|===
| Code or obligation | Prover | Notes

| Theory (type systems, lattices, metatheory, algebra) | *Agda*, rechecked in *Rocq* and *Lean* | Canonical invocation `agda --safe --without-K --cubical-compatible` with `-W error` and no warning suppressed (§2.1). The Rocq leg is Dedukti transport first, hand re-proof as the fallback; the Lean leg is re-proved until a released Lambdapi Lean exporter exists (§2). *No Mathlib*: a missing lemma is proved in Lean core.
| APIs, ABIs, engineering properties | *Idris2* | `%default total`; no `believe_me` or `assert_total`.
| Rust code | *Creusot* with *Pearlite* contracts, and *Verus* | On the code. Kani for `unsafe` and FFI seams, and Aeneas where Rust implements an Agda theorem, alongside and never instead (§1.2, §4.1).
| Ada code | *SPARK* | GNATprove.
| Concurrency protocols | *TLA+* (a §4 exception) | A finite model check is `tested-only`, with its bounds, not `proven`.
|===

Grades are §8 Proof Witness Grades (`PWG-3` … `PWG-1`), recorded per claim in
`PROOF-STATUS.adoc` and derived from receipts.
